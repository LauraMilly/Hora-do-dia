## Sobre o Projeto

Este projeto exibe o horário atual do sistema em que está sendo executado e altera o layout da página automaticamente de acordo com a fase do dia: manhã, tarde ou noite. O objetivo é oferecer uma interface dinâmica e visualmente agradável que se adapta ao ambiente temporal do usuário.

## Funcionalidades

- Exibe o horário atual em tempo real.
- Modifica o estilo visual (cores, imagens, etc.) conforme a fase do dia.
- Layout responsivo e adaptativo.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

## Como Usar

1. Clone este repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Veja o layout mudar conforme o horário do sistema.
